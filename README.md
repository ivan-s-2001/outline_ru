# Outline PHP

Самостоятельная локальная система базы знаний и управления рабочим временем на **Yii 2 + PHP + MariaDB**. Проект не требует Node.js, Yarn, Vite или Docker.

## Возможности первого рабочего релиза

- установка первого администратора через браузер;
- ФИО в полях «Фамилия / Имя / Отчество»;
- пользователи и роли `admin`, `manager`, `member`;
- коллекции и документы;
- история версий документов;
- комментарии и закрытие обсуждений;
- полнотекстовый поиск MariaDB с резервным LIKE-поиском;
- недельный и месячный график;
- смены, отсутствия, переработки и недоработки;
- заявки на отпуск с расчётом рабочих дней;
- производственный календарь;
- дежурства по залам;
- Redis для кэша и сессий включается через `.env`;
- интерфейс на русском языке.

## Требования OSPanel

- PHP 8.2–8.4;
- MariaDB 10.6+ или 11.x;
- Composer;
- расширения `pdo_mysql` и `mbstring`;
- Redis необязателен.

## Установка

Откройте терминал OSPanel в корне проекта и выполните:

```bat
osp\setup.cmd
```

Проверьте параметры MariaDB в `.env`, затем запустите:

```bat
osp\start.cmd
```

Откройте `http://outline.local`. При первом входе появится форма создания организации и администратора.

## Размер проекта

В репозитории нет `node_modules`. Composer устанавливается с `--no-dev`, поэтому остаются только runtime-зависимости. Общий кэш Composer находится вне проекта в `%LOCALAPPDATA%\Composer`.

## Диагностика

```bat
php yii doctor
php yii migrate --interactive=0
```

## Архитектура

- `controllers/` — веб-сценарии;
- `models/` — ActiveRecord и формы;
- `migrations/` — схема MariaDB;
- `views/` — серверный HTML;
- `web/` — CSS, JavaScript и точка входа;
- `osp/` — установка и запуск в OSPanel.

## Ограничения текущего этапа

Это рабочее ядро новой системы. Совместное редактирование в реальном времени, расширенный блочный редактор, импорт из сторонних сервисов и публичные страницы общего доступа ещё не реализованы. Схема базы для вложений, шаблонов, уведомлений и общего доступа уже заложена.
